# Medusa Games — pacchetto completo

Questa build ripristina la HOME completa di Medusa Games come pagina iniziale.

Struttura:
- `index.html` -> HOME Medusa Games
- `style.css`, `app.js`, `games.js`, `forgefall.js` -> home e navigazione
- `giochi/forgefall/index.html` -> Forgefall
- `giochi/forgefall/game.css` -> grafica Forgefall
- `giochi/forgefall/game.js` -> logica Forgefall
- `references/forgefall_target.png` -> riferimento visivo approvato

Il riferimento grafico NON sostituisce più la home.
