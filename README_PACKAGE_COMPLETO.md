# Medusa Games – pacchetto completo

Questo pacchetto include:
- Home completa di Medusa Games
- Pagina gioco Forgefall aggiornata con la versione interattiva di test approvata
- Struttura completa del progetto

## Avvio
Apri `index.html` per entrare nella home.
Da lì clicca su **Gioca a Forgefall** per aprire la pagina del gioco.

## Nota
La pagina `giochi/forgefall/index.html` è stata sostituita con la versione interattiva che rispecchia il layout approvato in anteprima.
