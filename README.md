# Medusa Games — FULL v9

Forgefall è stato ricostruito per seguire la nuova direzione grafica approvata: **un'unica mappa tridimensionale/cartoon**, con HUD integrato nella fortezza, griglia dentro il terreno e risorse/difese con asset premium.

## Forgefall v9

- mappa-isola unica con castello e mare;
- mare con leggero effetto animato;
- HUD Giorno / Mosse / Bastione / Punti integrato nella scena;
- griglia 6x6 sovrapposta naturalmente al terreno;
- asset nuovi per ferro, oro, ghiaccio, fuoco, legno e rame;
- cannone, torre arcieri, balestra e scrigno con grafica premium;
- selezione elemento + pulsante INFO;
- INFO con descrizione, danni, cadenza, bersaglio ed effetto;
- casse apribili: +2 / +3 / +4 mosse;
- 5 mosse iniziali;
- tris materiali → struttura;
- tris strutture uguali → upgrade;
- orda automatica a 0 mosse;
- boss/officina ogni 10 giorni;
- layout responsive desktop/mobile.
