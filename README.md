# Medusa Games — Full v4

Questa versione mantiene la home Medusa Games e rifà completamente **Forgefall**.

## Novità principali di Forgefall v4

- layout ripensato per desktop e mobile;
- esperienza orizzontale più leggibile;
- griglia 6x6 per le fusioni a sinistra / sopra;
- **campo di battaglia separato** dove i mostri arrivano da destra verso il bastione;
- strutture e mostri con grafica 2D più definita;
- livelli delle strutture leggibili anche visivamente:
  - livello 1 = look base;
  - livello 2 = variante metallica;
  - livello 3+ = variante dorata;
- casse del fabbro apribili con tap/click.

## Struttura file

- `index.html` → home Medusa Games
- `giochi/forgefall/index.html` → pagina del gioco
- `giochi/forgefall/game.css` → stile del gioco
- `giochi/forgefall/game.js` → logica del gioco

## Pubblicazione

Carica tutto il contenuto dello ZIP nella root del repository GitHub Pages, mantenendo le cartelle.
